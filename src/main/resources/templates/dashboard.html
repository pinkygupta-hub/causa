🎯 What is CAUSA?

CAUSA is an advanced Root Cause Analysis (RCA) system designed to automatically detect, analyze, and diagnose issues in Kubernetes workloads. Using AI-powered analysis, CAUSA helps DevOps teams quickly identify and resolve production incidents.

✨ Key Features

  • Automated workload scanning and monitoring
  • AI-powered root cause analysis
  • Integration with Prometheus alerts
  • Comprehensive log analysis
  • Real-time analysis tracking
  • Actionable remediation suggestions

🚀 Getting Started

To enable RCA analysis for your workloads, add the following label to your pods:

kruize/rca: enabled

CAUSA will automatically scan and analyze labeled workloads based on your configured schedule.
